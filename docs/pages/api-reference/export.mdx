# Export

<Callout type="warning">
  Rate limited: 1 export/hour on the free tier, 10/hour on Pro.
</Callout>

## `GET /v1/export/snapshots`

**Query parameters**

| Param | Type | Notes |
|---|---|---|
| `network` | string | Required |
| `from` | ISO timestamp | Required |
| `to` | ISO timestamp | Required |
| `format` | `csv \| json` | Default `csv` |

**Response**: file download (CSV or JSON).

## `GET /v1/activity/stream`

Server-sent events (SSE), not a request/response call — the connection stays open and pushes named events as they happen: `blob_registered`, `blob_activated`, `blob_deleted`, `sp_joined`, `sp_left`, `sp_health_change`, `epoch_transition`, plus `connected` on open and periodic `heartbeat` keep-alives.

<Callout type="info">
  Events arrive in bursts on the backend's sync cadence (every few minutes), not instantly on registration — a quiet stream for a few minutes is expected, not a sign of a broken connection.
</Callout>

| Param | Type | Notes |
