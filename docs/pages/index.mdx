# Shelby Analytics

Shelby Analytics is a community-built analytics dashboard for the **Shelby Protocol** —
a decentralized blob storage network built on Aptos. It tracks network health, storage
providers (SPs), blob registry activity, and economics across **shelbynet** (primary)
and **testnet**.

This is an independent, third-party project — not published or maintained by the Shelby
core team.

## What you'll find here

- **[Getting Started](/getting-started)** — how to read the dashboard, what the metrics mean,
  and how the two networks (shelbynet / testnet) differ.
- **[API Reference](/api-reference)** — the public `/v1/*` HTTP API for pulling raw network, provider,
  epoch, and blob data programmatically.
