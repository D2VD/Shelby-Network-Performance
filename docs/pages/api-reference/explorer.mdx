# Explorer

## `GET /v1/explorer/transactions`

**Query parameters**

| Param | Type | Notes |
|---|---|---|
| `network` | string | Required |
| `type` | `register_blob \| all` | |
| `address` | string | Filter by sender |
| `limit` | number | Default 50 |
| `cursor` | string | Cursor-based pagination |

**Response**

```json
{ "txs": [], "nextCursor": null }
```
